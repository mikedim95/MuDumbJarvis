# Agent portrait catalog

The current team uses the first five portraits. The four reserve portraits give new hires distinct faces.

## Image generation prompts

All nine portraits were generated with the built-in image generation tool. Each used this shared brief and one design from the table.

> Use case: stylized-concept. Square portrait for a science-fiction agent roster in a dark interface. A single original helmeted synth character, head and shoulders, facing the camera at eye level. Premium practical-effects sci-fi movie prop photography, a little tactile wear, physically plausible brushed metal, smooth lacquer, black techwear collar. Elegant French electronic-music stage-helmet energy and cinematic space-opera design. Keep the helmet silhouette clean, graphic and recognizable at 100px. Center the full helmet in the middle 65 percent, generous headroom, shoulders cropped at bottom, soft key from upper left, thin rim light, muted deep graphite-blue studio background. No words, letters, insignia, logos, watermarks, frame, extra people or human faces.
